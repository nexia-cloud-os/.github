# Nexia

**AI-Native Manufacturing Cloud Operating System**

Nexia connects manufacturing situations, accountable decisions, coordinated
work, and outcome review. Business Apps extend the platform through explicit
SDK contracts, with tenant isolation and governed AI execution.

## Build with Nexia

| Developer tool | Purpose |
| --- | --- |
| [CLI](https://github.com/nexia-cloud-os/cli) | Create a local App preview, validate its manifest, and work with an AI coding assistant |
| [Developer protocol](https://github.com/nexia-cloud-os/dev-protocol) | Versioned manifest schema and validation |
| [Developer client](https://github.com/nexia-cloud-os/dev-client) | Discover a Nexia host's supported developer capabilities |

The developer tools are experimental alpha releases. Local preview is available;
remote App execution, developer billing, and self-service deployment are still
being built. Each package documents its supported behavior.

Core, business App implementations, and internal runtime services are maintained
in private repositories. Public developer tools expose contracts without
distributing Core implementation source.

Report developer setup, SDK, CLI, Docker, AI-tool and sandbox problems in the
[central developer support tracker](https://github.com/nexia-cloud-os/developer-support/issues). Search existing reports first;
never include credentials, private Core source or customer data.
